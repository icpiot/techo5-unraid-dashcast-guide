# Echo Show 8 layout

The recovered conversation identified Echo Show 8 layout as the relevant optimisation topic, but the earlier private transcript was not available in the reference export. The recommendations below are limited to layout choices supported by Dashcast's documented behavior.

## Use a dedicated landscape dashboard

Create a dashboard/view specifically for the Echo Show 8 rather than forcing a dense desktop dashboard to fit. Keep important status and controls near the top and avoid frequent scrolling.

## Design for the rendered screen

Prefer:

- large, high-contrast text;
- fewer cards per row;
- short labels and compact secondary information;
- comfortable touch targets;
- a stable layout that does not continually resize as data changes.

## Keep motion modest

Avoid unnecessary animated cards, rapidly changing graphs, and long pages. This is a readability recommendation, not a claim about measured latency.

## Test with the actual device

Use the selected dashboard on the Echo Show and adjust one row or card at a time. Keep changes in Home Assistant's dashboard configuration; the verified setup does not require special Echo Show CSS in Dashcast.

No private IP address, token, or unverified device-specific CSS is included here.
